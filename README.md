# ET7 website

Standalone ET7 website based on the AW9 reference. English/Hindi, Android APK download, responsive layout.

Build: `python3 scripts/build_pages.py`

Deployment: GitHub Actions publishes `main` to https://seo168.github.io/et7-website/.

Reference banners retain original AW9 artwork. Copied promotional examples require ET7-specific verification before use as product claims.
